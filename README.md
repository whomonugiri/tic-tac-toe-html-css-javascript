# Tic-Tac-Toe with HTML, CSS and JavaScript

A beginner-friendly, two-player browser game from **DevNinja**. No frameworks, external dependencies, installation, account, server, or internet connection are needed to play.

## Run the game

1. Click **Code → Download ZIP** on this repository and extract the ZIP.
2. Open **game/index.html** in a modern web browser.
3. Keep `index.html`, `style.css`, and `script.js` together inside the `game` folder.

You can also clone this repository and open `game/index.html`.

## How to play

- Two players share one device. X starts, then O.
- Click or tap an empty square. Match three marks in a row, column, or diagonal to win.
- A full board with no winner is a draw.
- Use **Restart game** to clear the board and start again with X.
- Keyboard: press Tab to focus a square, then Enter or Space to play.

## Features

- Alternating turns, all eight winning lines, draw detection, and winning-square highlights
- Occupied-square and post-game move guards
- Restart with cleared marks, highlights, status, and focus returned to the first square
- Responsive grid, visible keyboard focus, labeled cells, and a live turn/result status

## Project files

- `game/index.html`: page structure, nine square buttons, status, and restart control
- `game/style.css`: layout, colors, responsive sizing, and focus styles
- `game/script.js`: game state, events, win/draw checks, and restart logic
- `tests/test-game.js`: focused behavior and opening-sequence tests
- `tests/exhaustive-game.js`: independent reachable-state and transition checks

## Tests

Playing only needs a browser. Running the tests additionally needs Node.js (a current LTS version is suitable). No npm packages are required.

From the repository folder:

```sh
node tests/test-game.js
node tests/exhaustive-game.js
```

The tests cover all 5,478 reachable board states, 16,167 legal transitions, and 33,135 occupied-square or post-game guard attempts. All eight winning lines for both players, final-square wins, status text, labels, highlights, and restart behavior are checked.

These tests execute the actual game JavaScript in Node.js with a small DOM test double and static HTML/CSS checks. They do not replace real-browser, rendered-layout, keyboard, screen-reader, or cross-device testing.

## Learn and experiment

HTML defines the page structure, CSS controls its appearance, and JavaScript handles game state and actions. Change one small thing, save, then refresh the browser. Start with colors or the heading. If styles or clicks stop working, check filenames and the browser's Developer Tools Console.
